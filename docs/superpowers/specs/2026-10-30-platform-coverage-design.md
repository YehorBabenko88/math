# ADR: mandatory platform-complete test coverage

Status: accepted by independent design reviewer before strict-runner changes; implementation and hosted qualification remain separately reviewable.
Base: Math PR103 0b75c0a3583f9823d2b554806468fa541f20b35c. Request: unified-system PR10 2fdd512bd06d3cb90b6c722e5f839f8ed159931f, docs/CODEX_NEXT_STAGE_20261030.md (embedded old Unified pin is superseded by verified current head).

## Root cause and contradiction
The current test-full-ci.mjs requires pass==tests, skipped==todo==0 for every unfiltered Linux run. Exact-head hosted Linux Node22/24 x PG16/18 registers 1147 tests, including 22 tests guarded by process.platform!==win32; all four cells necessarily fail. Those assertions need Windows PowerShell 5.1, PowerShell 7, .NET Framework csc/CodeDOM, and one explicitly hosted-only offline CLI fixture. Linux cannot satisfy them. Disguising these skips as passes would invalidate evidence.

## Decision proposed
Mandatory Linux portable matrix Node22/24 x PostgreSQL16/18 plus mandatory actual Windows Node22/24 lanes. Linux executes every portable test including all PostgreSQL and native PDF assertions. Windows executes22 exclusive Windows tests plus3 explicitly replicated cross-platform callbacks (25 original identities). Both Windows shells and Framework compiler are preflight requirements; absent dependencies fail. Hosted-only offline fixture may run only on GITHUB_ACTIONS Windows; physical/native qualification remains BLOCKED. No Windows PostgreSQL installation is necessary because none of these 22 assertions consumes PostgreSQL; the Linux four cells qualify both database versions. The POSIX directory-mode assertion remains exclusively portable/Linux.

Every original assertion is preserved. Structurally extract platform-specific registrations into separately named *.windows.mjs files at the same tests directory depth (relative fixture/import URLs remain valid). Mixed bootstrap, G0 contracts, and offline-preflight files retain portable assertions; only dependency/helper definitions needed by Windows tests may be shared or duplicated. npm test retains full developer discovery via exact locked *.test.mjs, *.windows.mjs and *.cross.mjs globs; all1152 current identities remain discoverable, and missing local prerequisites never imply qualification; mandatory CI uses explicit platform inventory, not name filtering. No test-name/skip filters, retries, NODE_OPTIONS selectors, only flags, skip/todo acceptance, or lexical greenwashing.

## Identity accounting and policy change
Replace the impossible requirement "unfiltered Linux runs every test" with "the union of mandatory Linux and Windows inventories contains every source-owned identity, every eligible identity passes without skip/todo/cancellation, and no identity is executed twice within a lane." Matrix replication is deliberate: portable identity appears once per Linux Node/PG cell; Windows identity once per Windows Node cell. Unique inventory is counted after deduplication of required cell replication, not as accidental duplicate execution.

Pin the baseline logical test inventory from actual node:test events and cross-check all 1147 against existing exact-head hosted TAP, including 12 dynamically nested children. Identities include original source file, full parent/name chain and occurrence identity; line/column are retained for audit but moving a registration cannot redefine its logical identity. Newly added harness tests extend the manifest explicitly. A custom event reporter must capture actual execution identities and terminal status. Compare events against committed expected identities: dropped, extra, duplicate, substituted (including same-count replacement), skipped/todo, failure/cancellation and missing final summary fail closed. File inventory must cover the exact source files and detect untracked test additions. Artifact aggregation independently verifies every mandatory lane, platform/runtime, source HEAD/tree, run/attempt, and union, and rejects missing/extra/duplicate cells. Existing strict runStrictTests fixture API remains zero-skip; no weakened fallback.

## Alternatives
1. Keep unfiltered Linux zero-skip unchanged: impossible under actual Windows API prerequisites; rejected.
2. Run whole suite on Linux and Windows and allow platform skips: preserves visibility but violates zero-skip eligibility, duplicates portable execution and mixes POSIX skips into Windows; rejected.
3. Explicit disjoint platform source groups with runtime identity receipts: selected proposal, auditable eligibility and strict actual assertions.

## Implementation and review boundaries
Negative mutation tests first: missing/extra/duplicate/substituted/nested identity, skip/todo/cancel/fail, fake pass counts, wrong source/cell/platform/runtime and missing artifact. Preserve every existing assertion and review extraction diffs against base. Keep runtime/disposable PostgreSQL URL guards, locked PDF requirements, immutable action pins, tracked-source before/after provenance, source/dependency verification, and exact isolated synthetic-branch exception. Source-only port collision correction is permitted only after hosted reproduction and must preserve bounded behavior/assertions. Never change production services, PostgreSQL, ACL/firewall, SSH/Tailscale, physical G1 or exchange orders. Publish a new independent Draft PR and collect exact-head hosted results plus actual artifact ZIP SHA256; queued/cancelled/failed/NOT_RUN remain accurately distinguished.

## Independent review additions
Baseline source authenticity is pinned by repository URL, exact original hosted run URL, original commit/tree and each of all 188 original test-file Git blob IDs plus SHA256/byte length. Mechanical extraction proof is stronger than callback-only hashes: every original test file must reconstruct byte-for-byte from its portable prefix and extracted Windows suffix, or be renamed byte-for-byte. Windows duplicate helper/import prefix is itself copied exactly. This preserves every callback, assertion, option, registration name and loop, rather than trusting names/counts. A checker fails before tests if reconstruction or original blob/hash differs. Source file -> destination mapping and per-identity original/destination locations are committed. New harness tests occupy new files and extend inventory explicitly.

1147 means 1135 top-level test registrations plus 12 nested child tests (not suite summaries); all are terminal test identities and all must pass. The 22 Windows tests are all top-level, with no nested children. Linux owns 1113 original top-level tests plus all 12 nested children =1125. Nine deliberately repeated same-name registrations at evidence-receiver-strict.test.mjs:2 require a per-source/full-parent/name occurrence index; preserve all nine. Parent and child each have independent assertions, so count each terminal once and never count per-file/root summaries as tests. Baseline local Windows run registered all1147 but had1039 executed passes and108 skips (DB/PDF/hosted prerequisites): inventory evidence only, never qualification. Cross-check identity multiplicities against authenticated exact-head hosted Linux TAP1147.

Aggregator verifies actual process.versions.node major, actual PostgreSQL SELECT server_version for Linux, exact platform, raw event-file SHA256, immutable manifest/source-proof digest and source HEAD/tree. Exact required cell keys linux-22-16/linux-22-18/linux-24-16/linux-24-18/windows-22/windows-24 are mandatory; one receipt per cell, with zero failed/cancelled/skipped/todo tests. Native Windows compiled/synthetic assertions do not qualify physical G1, token APIs, production services or Windows PostgreSQL.

## Cross-platform assertion refinement
Three original logical identities are intentionally cross-platform: offline-preflight child-environment/canonical containment (Windows-only case-insensitive path assertion) and detached-journal symlink replacement phase1/phase2 (Windows synthetic receipt versus POSIX real symlink assertion). Extract their unchanged registration bytes into *.cross.mjs with exact duplicate prerequisite helpers; execute each once in each of all six mandatory cells. Windows cells therefore have22 exclusive+3 cross=25 original test identities; Linux cells1125 include3 cross. The unique union stays1147. Runtime assignment encodes exclusive Windows, exclusive Linux and explicit cross as distinct categories, and the aggregator validates exact membership per cell. Windows has Node/Git/PowerShell/Framework prerequisites, temporary SQLite and synthetic filesystem helper dependencies for these cross callbacks. Source audit of every process.platform use found no further Windows-only conditional assertions: remaining uses select fixture paths/symlink kinds, or intentionally POSIX-only assertions; pure helper tests explicitly supply Windows/Linux values and already exercise both in Linux. This is not a claim that every Linux-owned test was runtime-qualified on Windows.
