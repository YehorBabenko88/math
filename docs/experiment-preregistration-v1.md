# Experiment preregistration — R18 partial DEV
This draft extends R17 with per-policy budget counters, command byte bindings, a one-shot UUID claim, start CAS, terminal byte CAS and read-only command lookup. The same command replay cannot return a fresh claim/start. Unknown COMMIT throws; lookup never grants execution. No automatic reclaim; crash may lose work. All authority flags false.
A dedicated isolated pool is required. ROLLBACK before BEGIN discards an accidental outer transaction (not safe for a shared pool). DB name/role/version are necessary but not sufficient isolation checks. SQL must not be applied until review and Q-approved provisioning. No manifest change.
Trusted host resolvers must verify exact references; the adapter requires them but does not implement their evidence verification. No user callbacks or direct worker SQL. UUID token is a lab claim binding, not authenticated worker identity or a time-limited lease. No positive authority. Owner provisions budget rows and function-only ACL after review.
Remaining gaps: semantic duplicate across J roster reorder, durable invalid/refused proposal accounting, bounded command admission, claim lease/epoch, authenticated worker and metric resolver, command lookup exact bytes comparison, true clean pool enforcement, role provisioning and live PG18 acceptance. New command for identical terminal records a command row; only exact command replay is read-only at logical row level. No cross-store atomicity, Holdout or trading.

R19 delta: semantic trial uniqueness across roster reorder, full canonical binding comparison, and proposal charge on new duplicate command. This narrow draft deliberately denies retries of the same semantic binding pending explicit retry policy. Duplicate reservation returns the requested identity with DUPLICATE, not a new dispatch receipt. Dedicated physical connection factory is a trusted host requirement; no ROLLBACK of a borrowed client. Factory custody still needs independent verification. Live PG18, role grants, authenticated worker/lease/epoch, bounded rejection retention, receipt recovery and exact lookup binding remain open. X8 hardened codec used only in test composition; no foreign file changes.
