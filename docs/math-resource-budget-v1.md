# Resource budget v1 — DEV_CANDIDATE
Single-thread ownership; nested kernels share one counter. Preflight checks conservative bounds but does not consume them. Charge before work; reserve before allocation; release only after actual disposal. Byte categories are logical accounting and do not measure RSS or authorize execution. Output bytes are separately tracked, and actual write bytes must also be charged. Limit failure is terminal; cleanup may release memory, but no qualified partial output is permitted. Invalid argument errors require caller refusal. Safe integers only, ASCII operation IDs up to 64 characters, at most 256 distinct kinds including predefined categories; excess kind count refuses atomically. No scheduler, network, persistence or trading. Native observer and concurrency remain outside scope. Microbenchmark measures only local wall/process CPU, not tree memory or end-to-end performance. Independent qualification remains pending.
