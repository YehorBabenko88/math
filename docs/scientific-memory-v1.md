# Scientific Memory v1

The Math producer calculates a descriptive autocorrelation of consecutive close deltas from pinned, contiguous Bybit OHLCV observations. The dataset preserves the original numeric strings and has a canonical rows SHA-256. The record adds a dataset identifier, UTC bounds, mathematical space, algorithm version, parameters, computed values, an independent rational reference and exact error strings. Its claim status describes a specified threshold on that reference. It is not a statement about out-of-sample behavior or exchange completeness.

Persist records with `scientific_memory.save` using a separate writer that can `SELECT` and `INSERT` into `public.mu_scientific_runs`. The table, defined in `python/scientific_memory.sql`, is installed by an authorized database operator. This schema is separate from the existing historical migration ledger. Give the HTTP reader a role that can only `SELECT` from this table. The reader verifies the hash of each stored payload and does not rerun ACF. The route is `GET /v1/scientific-memory?symbol=BTCUSDT&limit=50`, with a maximum of 100 results and schema `math.scientific-memory.list.v1`. A valid empty symbol returns an empty records array. The read-only HTTP server binds to loopback.

To start the reader from a source checkout, supply `SCIENTIFIC_MEMORY_READ_DSN` and run `python python/scientific_memory.py --port 18767` with psycopg installed. The service does not migrate, ingest exchange data, start trading, or configure Terminan. Its loopback boundary and database roles require independent deployment and operational acceptance before any production adoption.
