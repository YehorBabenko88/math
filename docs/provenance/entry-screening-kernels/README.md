# Bounded numerical screening kernels

These three Math kernels accept exact literal numerical observations; Terminan owns fold selection, metadata grouping, thresholds, verdict reasons and the sole PaperEngine. No trade DTO, simulation, source authentication or execution authority enters this API.

The explicit ordered binary64 ABI uses sequential addition on every host. It matches the archived Python 3.11 bootstrap draw and linear-quantile order. Python 3.12 historical built-in sum differences are retained as exact vectors, not silently hidden under one ABI. Existing paired/block bootstraps are byte unchanged.

Profit-factor NO_LOSSES is tagged and produces no invented zero. The >=1e100 exclusion is available only through LEGACY_LT_1E100_V1. Empty eligible factor mean is null; callers choose any research verdict.

The additive executed_notional_consistent predicate only checks finite nonnegative zero/nonzero identity in literal lossless binary64 or plain Decimal presentation domains. It never proves exact quote quantity, OHLC bounds, source integrity or permission.

Verification: 25 new cases; reviewed full source 255 and wheel 232 on Python 3.11/3.12; seven strict CI groups replayed in source and wheel modes on both runtimes. No native, SourceFence, network, SQL, thread launch or installation. No legacy obligation retired.
