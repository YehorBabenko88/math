Numeric leaves are plain finite lossless binary64-compatible integers or floats; booleans, numeric subclasses and implicit Decimal conversion refuse. Fees are nonnegative. Optional signed MAE, MFE and R are caller declarations with no inferred sign convention. Holding time is a plain integer in [0, 2**53-1] milliseconds.

Each optional summary has count, total and mean; an absent field has count zero, total 0.0 and mean None. Explicit observed zero has positive count and mean 0.0. No excursion or missing declaration is manufactured.
