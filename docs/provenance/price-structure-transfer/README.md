# Price structure numerical transfer

`price_structure_patterns` owns strict high/low swing and three-range gap calculations. It preserves original price values, strict tie comparisons, and dependency windows. Codes0/1 represent high/low swings;2/3 upward/downward gaps. Each record carries a half-open dependency index interval so Terminan can bind explicit availability. No bar duration, historical availability, coverage, trading permission or source authentication is inferred.

Original whole source and tests are archived with exact Git identities. SMC trend/BOS/sweep/order-block policy, multi-timeframe context and all original Data consumers remain until their separate transfer is accepted. No Data deletion or516-inventory deduction occurs here.
