# G0 read-only design

Use the existing ADMINIT observation model, with a separate normalized G0 collector rather than changing Execute/isolation admission. Fixed new acceptance-root inspection only; no historical roots, creation, writes or network probes. Read token identity/Medium RID via a fixed Windows whoami query, inspect root/source ancestor reparse and ACL ownership/write grants, and inventory ActiveStore firewall policies against current connection profile categories. Raw SIDs/paths/rules remain in process memory and never enter stdout/artifacts. Missing privilege, ambiguity, unreadable policy or inaccessible root is UNKNOWN/BLOCKED. Firewall inventory is not proof of effective loopback or process isolation.

Node validator consumes only exact, bounded, normalized enum/boolean/count fields, requires explicit closed authority values and rejects extensions. Even perfect snapshots remain localExecute=false, isolationConfirmed=false and G1 BLOCKED. Observation checks are not attestation. No collector execution on ADMINIT; PowerShell parser/static checks and synthetic JSON tests only. No psql/database driver/socket probe/service query is allowed. The separate collector does not modify the previous isolation verifier or its guards.
